# v0.1.0 — Callable minimal model

First version: a run that takes N parties, M voters, and a seed, votes at random reproducibly, and returns raw votes plus counts and a winner or tied parties.

## Scope

In: function `simulate`, thin CLI, JSON scenario file, entities `Voter` and `PoliticalParty`, seed.

Out: demographics, districts, campaigns, UI, persistence, remote scenario load, party names as used fields.
