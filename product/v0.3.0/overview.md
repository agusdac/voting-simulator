# v0.3.0 — Party spectrum from GDP shares

Parties with nine GDP spend shares can be labeled `far_left` … `far_right` with a conviction percent, via a module and `classify.py`. Affinity voting is unchanged.

## Scope

In: prototype L1 classification, party fields, standalone script.

Out: classification inside `simulate`, a second political axis, voter labels.
